# QField Plugins

If you are familiar with QGIS plugins, you will know that plugins add additional functionalities to your core application.

QField comes with a set of plugins, which you can activate through the settings menu.

!!! note
    A permission dialog is shown prior to activating a plugin, providing you with the possibility of granting or denying individual plugins.

!!! Workflow

    1. Open the **Side Dashabord**
    2. Tap on the **3-dotted menu** and open the plugin manager :material-puzzle:
    !![Plugin Local](../../assets/images/settings-plugins.png,300px)
    !![Plugin Applications](../../assets/images/application-plugins.png,300px)
    3. Either choose from the existing application plugins or import your plugin through the **Local Plugins dialog**.

!!! Note

    Everytime you install a plugin, you will be asked for granting permissions.

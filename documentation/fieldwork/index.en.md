# In the Field

This section is dedicated towards the people in the field.
If you are doing any kind of data collection and do not know how to edit, add or start a tracking section, you will find specific workflows on how to do it in QField.

Images, clear descriptions and videos will support you to collect the data you need.

Start with [creating a project in QField](../fieldwork/create-project.md) directly and go out.
